# Portfolio landing page

Static single-page site for Kened Kqiraj's applied data science portfolio.

## Preview locally
1. From the repository root, start a simple static server:
   ```bash
   python3 -m http.server 8000
   ```
2. Open http://127.0.0.1:8000/ in your browser.

## Notes
- The page lives in `index.html` with styles in `styles.css`.
- No build step is required; any static server works.
